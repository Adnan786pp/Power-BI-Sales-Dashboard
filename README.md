SALES DASHBOARD – POWER BI

Project README

**Project Overview**

An interactive Sales Dashboard built using Microsoft Power BI to analyze and visualize sales performance. The dashboard provides key KPIs including Total Sales, Quantity, Rate, and Average Order Value, along with Product-wise and Region-wise Sales Analysis, Order Priority Filtering, Date-based Analysis, and Target vs. Actual Sales Tracking.

**Key Features**

Total Sales and Quantity KPIs

Rate and Average Order Value analysis

Product-wise and Region-wise sales analysis

Order Priority filtering

Year, Quarter, and Month-based analysis

Target vs. Actual Sales tracking

Interactive charts and dashboard filters

**Tools & Technologies**

Microsoft Power BI

Power Query

DAX

Data Visualization

**Objective**

The objective of this project is to transform sales data into an interactive and user-friendly dashboard that helps analyze performance, identify trends, monitor KPIs, and support data-driven decision-making.
